Авторизация через браузер не нужна — сервис работает без логина. Прямые API-вызовы требуют Bearer-токен.

02
Создаём канал

Канал — набор настроек: режим генерации, голос, промпт, теги по умолчанию.

  • Перейти на /channels → нажать «+ Создать канал»
  • Выбрать режим: B-roll + Голос или HeyGen Аватар
  • Для канала о здоровье — нажать «👴 Дедушка Врач», всё заполнится автоматически
  • Нажать «Создать»
⭐

Один сервис = несколько каналов на разные ниши. Каждый со своим голосом, промптом и YouTube-аккаунтом.

03
Подключаем YouTube Готово к подключению

На карточке созданного канала нажать «Подключить YouTube».

  • Создать проект в Google Cloud Console → включить YouTube Data API v3
  • Создать OAuth 2.0 Client ID (тип: Web Application)
  • В Authorized redirect URIs добавить:
    http://shorts.v3techbots.online/api/channels/oauth-callback
  • Добавить свой Google email как Test User (OAuth consent screen → Test users)
  • Скачать client_secret.json → загрузить на сервер в /root/shorts-factory/secrets/
  • Нажать «Подключить YouTube» → пройти авторизацию Google
✅

После авторизации статус YouTube на карточке канала станет зелёным. Квота: 6 видео в день на один Google Cloud проект.

⚠️ При ошибке «приложение не верифицировано» — нажать «Дополнительно» → «Перейти на shorts-factory». Это нормально для тестового режима.

04
Добавляем темы

Тема = одно видео. Два способа добавить:

  • Вручную: /topics → «+ Добавить» → вписать тему и выбрать канал
  • Через AI: нажать «✨ AI-генерация» → выбрать канал → Claude создаст 20 тем по нише → отредактировать → «Сохранить»
  • Можно указать дату запуска — планировщик сработает автоматически
🤖

AI-генерация выдаёт 20 уникальных тем за раз. Рекомендую сразу заполнить очередь на 2–3 недели вперёд.

05
Запускаем генерацию Главное

Нажать ▶ рядом с темой — немедленный запуск. Или указать дату — автозапуск по расписанию.

06
Публикуем

По умолчанию видео загружаются как Unlisted (доступно по ссылке, не в поиске).

  • Открыть видео на /videos/[id] → нажать «Опубликовать» → станет публичным на YouTube
  • Нажать «Instagram» → опубликуется как Reel
  • Или включить Авто-публикацию в настройках канала — всё происходит само
  • Если видео упало с ошибкой — нажать «Повторить», пайплайн продолжит с того места

FAQ

Частые
вопросы

Сколько стоит одно видео?
B-roll режим: ~$0.003–0.05 (скрипт + голос; Pexels бесплатно). HeyGen режим: зависит от тарифа HeyGen, от $0.08 до $0.50. Точная стоимость видна в логе шагов на странице видео.
Почему видео загружается как Unlisted, а не Public?
Защита от случайных публикаций. Сначала посмотри результат — потом нажми «Опубликовать». Или включи авто-публикацию (auto_publish_public) в настройках канала — тогда всё идёт сразу в public.
Видео упало с ошибкой — что делать?
Открой /videos/[id], прочти текст ошибки в логе. Нажми «Повторить» — пайплайн продолжит с того шага, где остановился. Готовые артефакты (скрипт, голос, b-roll) не пересоздаются.
Можно больше 6 видео в день?
Да — нужно несколько Google Cloud проектов (каждый даёт 10 000 units/день = 6 загрузок). В поле google_cloud_project_id канала укажи нужный проект, соответствующий client_secret.json положи в secrets/.
Как настроить аватар «Дедушка Врач» в HeyGen?
1. Зарегистрируйся на heygen.com → получи API ключ. 2. Создай Photo Avatar — загрузи фото пожилого доктора. 3. Выбери русский голос. 4. Скопируй Avatar ID и Voice ID. 5. В настройках канала выбери режим HeyGen и вставь эти ID — или нажми пресет «👴 Дедушка Врач».
Как подключить Instagram?
Нужен Instagram Professional аккаунт + Facebook App с правами instagram_content_publish. Добавь META_APP_ID и META_APP_SECRET в .env → перезапусти API → на карточке канала появится «Подключить Instagram».
Где смотреть статистику?
/dashboard: KPI (в очереди, опубликовано сегодня, всего, средняя стоимость) + график за 30 дней. Детальный лог — /videos/[id] → «Лог генерации».
Как удалить канал или тему?
Каналы: кнопка 🗑 в правом верхнем углу карточки. Темы: кнопка 🗑 в строке таблицы. Удаление безвозвратное — подтверждение спросит перед удалением.
